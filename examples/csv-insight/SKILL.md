# CSV Insight — 表格洞察卡

## 做什么

输入一个 CSV 和一句问题，输出一张「体检 + 指标 + 结论 + 图」的 Markdown 卡片。

## 什么时候用

- 拿到一份陌生 CSV，想知道它能不能用（缺失率、重复行、异常值）
- 周报/日报需要一个能被引用的数字结论
- 做 dashboard 前先确认口径（分母是什么、时间窗是什么）

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| `csv_path` | 是 | 本地 CSV 路径，UTF-8 或 GBK |
| `question` | 是 | 一句业务问题，如「哪个渠道的转化最好」 |
| `time_col` | 否 | 时间列名，用于按周聚合 |

示例输入：

```json
{"csv_path": "data/orders.csv", "question": "哪个渠道转化最好", "time_col": "created_at"}
```

## 输出

一份 Markdown，包含四段：

```
## 体检
行数 / 列数 / 缺失率 top3 / 重复行
## 指标
（按问题选 2–4 个指标，写清分母）
## 结论
1. 带数字的一句话
## 图
ASCII 条形图（<= 40 字符宽）
```

## 步骤

1. 读取 CSV，先只取前 200 行推断 dtype 与分隔符；失败则退回 `csv.Sniffer`。
2. 计算体检三件套：缺失率、重复行数、数值列的分位数（p50/p95）。
3. 根据 `question` 里的关键词选择指标模板（渠道/时间/品类三选一）。
4. 生成 ASCII 条形图，宽度不超过 40 字符，保证在微信里不被折行。
5. 输出 Markdown，所有数字保留 2 位小数；样本量 < 30 时在结论前加警示。

## 工具

- Python 3.9+（标准库 `csv` / `statistics`，无第三方依赖）
- 可选：`pandas`（有则用，无则走标准库分支）

## 失败与边界

- 文件不存在 → 直接返回错误，不猜测路径。
- 编码不是 UTF-8/GBK → 尝试 `utf-8-sig`，仍失败则报告「编码未知」并给出前 3 行原始字节。
- 行数 < 30 → 正常输出，但结论前加「样本过小，结论仅供参考」。
- 分母为 0 → 该指标输出 `N/A`，不输出 0。
